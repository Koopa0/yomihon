# 蔵人 kurodo

> 読むのは蔵人、裁くのは主。

kurodo（蔵人，くろうど）是 Koopa 私有知識庫（`~/obsidian`）的本地閱讀與裁決介面，也是這座「蔵」的秘書役——為主上讀文件、傳達裁決、看管簿冊。

它做三件事：

- **閱讀**：把整座 vault 變成可讀、可導航、可搜尋的介面——課文、概念、報告、課綱，全部。
- **裁決**：讓「認證一則筆記」在讀完的地方一鍵完成。`ready` 只有 Koopa 能按，而 kurodo 就是那顆按鍵。
- **簿冊**（規劃中）：吸收 kura 的判官職責與 agent 工具箱——`check` / `exists` / `coverage`，vault 側的 agent 也透過這支 CLI 做事。

它永遠不做的事：

- 永不對外。單人、local-only，沒有部署這回事。
- 永不代寫、永不「修好」筆記。判官只報告，改檔的是人。
- 除了 `status` 一個欄位，永不寫入 vault。

生態位：kurodo 是 **yomihon（読本，日文課程閱讀器）與 kura（蔵，corpus 判官）兩者的繼承者**——兩者凍結服役至各自的退役閘達成；koopa0.dev 負責對外。kurodo 是這一切的人類終端。

**狀態**：設計完成（見 `docs/`），M0 實作起步。
