指定 Markdown 資料夾，啟動閱讀器：

```sh
yomihon ~/notes
```

開啟 `http://127.0.0.1:9610`，即可閱讀、瀏覽資料夾與搜尋。啟動不會改動筆記；閱讀期間讓指令持續執行，結束時在終端機按 `Ctrl+C`。

標頭的 `EN` 切換介面語言，正文不會翻譯。筆記可用契約允許的 `lang` 欄位宣告語言，例如 `zh-Hant` 或 `ja`。

狀態控制、課程、地圖與命令列報告需要 [[知識庫契約]]。設定步驟見 [[L02 Add a contract]]。
