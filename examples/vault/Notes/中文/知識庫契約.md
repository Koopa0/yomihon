一個 Markdown 資料夾不需要任何契約就能讀。契約的作用，是讓資料夾主動加入
yomihon 裡那些必須知道筆記語意的部分：有哪些類型、每種類型可以帶哪些狀態、
哪些目錄放的是知識、哪些目錄的內容不離開這台機器。

它放在 `System/schemas/vault-schema.toml`。這個知識庫裡的那一份就是可以照抄的
起點——整個 yomihon 只有這一個地方定義這些事，程式碼裡不存在它宣告過的任何
一份清單的第二份副本。

## 它長什麼樣子

```toml
[enums]
type = ["note", "lesson", "study-path", "moc"]

[enums.status]
note = ["draft", "ready", "published", "archived"]
```

真正有意思的是 `[[lifecycle]]` 那幾列，那是[[status 的生命週期]]的主題。

## 讀不到的時候

有契約但無法解析，和完全沒有契約，是兩件不同的事。yomihon 會在每一頁說出來，
並且關閉寫入面而不是猜——契約壞掉的資料夾，絕不能看起來像從來沒有契約的
資料夾。
