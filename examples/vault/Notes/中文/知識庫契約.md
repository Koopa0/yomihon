Markdown 資料夾不需要契約就能讀。契約宣告筆記類型、允許的欄位與狀態、課程與地圖類型、掃描範圍，以及命令列輸出的隱私邊界。

這些宣告集中在 `System/schemas/vault-schema.toml`，可從本知識庫的檔案開始調整。

## 它長什麼樣子

以下節錄宣告筆記類型與預設狀態清單：

```toml
[enums]
type = ["note", "lesson", "study-path", "moc", "concept", "inbox"]

[enums.status]
note = ["draft", "ready", "published", "archived"]
```

`[[lifecycle]]` 宣告允許的狀態轉移，見 [[status 的生命週期]]。上面的節錄不是完整契約。

## 讀不到的時候

契約無法讀取或內容無效時，頁面會顯示原因，停用狀態控制、課程與地圖。沒有可用契約與隱私宣告時，`check`、`coverage`、`exists` 也會拒絕執行。

> [!warning] 契約壞掉的時候，資料夾還是看得到
> 閱讀、資料夾導覽與搜尋仍可使用。
