Markdown 資料夾不需要契約就能讀。契約宣告要檢查哪些資料夾、筆記類型與各自在課程和地圖裡的角色、筆記可以寫哪些欄位、其中一些欄位能取哪些值，以及命令列輸出的隱私邊界。

這些宣告集中在 `System/schemas/vault-schema.toml`，可從本知識庫的檔案開始調整。

## 它長什麼樣子

以下節錄宣告筆記放在哪裡、兩種類型，以及筆記可以寫的欄位：

```toml
schema_version = "2"

[folders]
checked = ["Concepts", "Lessons", "Notes"]
domain_from = ["Concepts", "Lessons"]

[enums]
domain = ["yomihon", "japanese", "go"]

[fields]
common = ["type", "aliases", "lang", "created"]
required = ["type"]

[types.note]

[types.lesson]
role = "lesson"
fields = ["slug", "level"]
```

欄位清單是封閉的：筆記只寫 yomihon 定義、且契約給了它的欄位，加上 Obsidian 自己的 `tags`、`aliases`、`cssclasses`。`title` 與 `domain` 不寫：標題取內文第一個 H1，沒有就用檔名；領域取 `domain_from` 底下的第一層資料夾。還沒寫完的筆記寫 `draft: true`，見 [[草稿]]。上面的節錄不是完整契約。

## 讀不到的時候

契約無法讀取或內容無效時，頁面會顯示原因，並停用課程與地圖。沒有可用契約與隱私宣告時，`check`、`coverage`、`exists` 也會拒絕執行。

> [!warning] 契約壞掉的時候，資料夾還是看得到
> 閱讀、資料夾導覽與搜尋仍可使用。
