Markdown 資料夾不需要契約就能讀。契約讓 yomihon 知道筆記的語意：有哪些類型，每種類型可以有哪些狀態，哪些目錄放知識，哪些目錄的內容不離開這台機器。

它放在 `System/schemas/vault-schema.toml`，這些事只在這一個檔案裡定義。從這個知識庫裡的那一份開始改。

## 它長什麼樣子

```toml
[enums]
type = ["note", "lesson", "study-path", "moc"]

[enums.status]
note = ["draft", "ready", "published", "archived"]
```

`[[lifecycle]]` 那幾列是重點，見[[status 的生命週期]]。

## 讀不到的時候

有契約但讀不出來，和沒有契約，是兩件事。yomihon 會在每一頁說明，並且關掉狀態按鈕，而不是猜。

> [!warning] 契約壞掉的時候，資料夾還是看得到
> 目錄樹與最近更動不受契約管轄。停掉的只有需要語意的那幾面：狀態控制、學習路徑、地圖。壞掉的契約不會讓你看不見自己的檔案。
