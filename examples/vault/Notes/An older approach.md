Before the contract, types and statuses were guessed from directory names.

Archived rather than deleted. It was not wrong so much as unable to say when it
was wrong: a folder rename silently changed what every note in it meant, and
nothing anywhere could report that. [[The vault contract]] replaced it, and the
reason this note still exists is that the failure is worth remembering.
