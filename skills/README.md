# Skills

One skill, for agents that write the notes a yomihon-read vault holds.
[`yomihon-authoring/SKILL.md`](yomihon-authoring/SKILL.md) says which frontmatter
opens a capability, how a filename lets a wikilink resolve, the study-path
grammar, and the dialect the renderer treats specially. Install it where your
agent looks for skills: `.claude/skills/yomihon-authoring/` for Claude Code, or
the same folder under `.agents/skills`. A symlink here keeps one copy.
